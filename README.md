# 汐序 · Xixu

面向哈尔滨工业大学（威海）的 Android 校园工具。把课表、考试、成绩、校园消息和随手记录放在一个轻量应用里。

**当前版本：0.7.6 · Android 8.0+ · 非学校官方应用**

[下载 APK](https://github.com/socialistearth/Xixu-HITWH/releases/latest) · [新闻设置](docs/NEWS-SETUP.md) · [构建与测试](docs/BUILD.md) · [本次更新](docs/RELEASE-0.7.6.md)

## 功能

| 选项卡 | 可以做什么 |
| --- | --- |
| 查询 | 课表、考试、绩点与成绩；课程颜色区分；本地缓存；逐条或全部删除缓存 |
| 新闻 | 从校园 VPN 校主页发现消息，手机读取并调用自选模型精选；每日定时、立即获取、原文、复制链接及缓存管理 |
| 用户 | 统一身份认证资料、备忘录、校历与作息、启动同步开关和最短间隔、提醒管理 |

- 同步教务和获取新闻在主界面显示进度与步骤；需要人工操作时，点击“手动验证”才显示学校网页。
- 点击课程或考试，可创建应用内闹钟或预填系统日历日程。应用内闹钟不一定出现在手机“时钟”App 的列表中，可在“用户 → 提醒与数据”管理。
- 已同步数据可离线查看。未完成的读取会保留原缓存；待人工查看的新闻链接单独列出。
- 界面采用米白、深绿与浅绿，参考莱茵生命的简约科研气质；不使用游戏或学校官方标识。

## 安装与开始使用

1. 在 [Releases](https://github.com/socialistearth/Xixu-HITWH/releases) 下载签名 APK。同签名 0.5.x、0.6.x、0.7.x 用户可覆盖安装，升级前不要卸载。
2. 打开“用户”，填写自己的学号和统一身份认证密码。
3. 核对学期、第一教学周周一、每节课起止时间；这些设置决定课表日期和提醒时间。
4. 点击“同步教务”，需要验证码时按界面提示完成本人验证。
5. 如需校园新闻，在“用户 → 校园消息”填写兼容 Chat Completions 的 HTTPS 模型 API 地址、模型名称及密钥，再点“立即获取”。不需要 Docker 或新闻服务器。

新闻默认按 **2026 年入学的威海校区本科生** 计算年级与学期，这一身份目前写在 `LocalNewsPolicy.java` 中；其他年级用户需要先适配该规则，不能仅靠“关注方向”覆盖它。

## 新闻获取方式

通过学校 VPN 的“校主页”发现文章，限定近七天、一次最多20篇新文章，串行读取并保留访问间隔。支持校主页列出的威海新闻网和本部新闻网；优先使用页面实际提供的 VPN 链接，符合条件的单篇技术故障最多尝试一次对应官方 HTTPS 原文。不会枚举站内地址或遍历全站。

模型对读取成功的内容评分并生成摘要。图片、二维码和附件当前不识别，会在新闻详情提示；最终事项、资格和截止日期以学校原文为准。详细配置见 [新闻使用指南](docs/NEWS-SETUP.md)。

## 数据与运行边界

- 学校账号、密码、课程和业务数据保存在本机加密存储中，VPN 会话由 Android WebView 保存。
- 新闻精选会把文章文本、关注方向与学生画像发送给你选择的模型服务商，使用其 API 额度；不发送学校密码或 VPN Cookie。
- 验证码及学校要求的本人操作需要手动完成。学校网页改版可能导致读取失效。
- 定时新闻和提醒受 Android 通知、精确闹钟、网络及后台限制影响；定点任务不保证整点执行，首次使用请实际验证提醒。
- 本项目针对特定学校页面适配，尚不提供跨学校通用登录。最新验证范围见 [0.7.6 更新说明](docs/RELEASE-0.7.6.md)。

## 开发

使用 Java 17、Android SDK 35、Gradle 8.11.1、AGP 8.9.2；Android 原生负责登录、任务、存储与提醒，本地 HTML/CSS/JavaScript 构成主要界面。

```sh
# 独立开发包名，与正式版并存
./gradlew -PappId=edu.hitwh.fieldnote.dev :app:assembleDebug

# 离线 JavaScript 回归
node --test tests/*.test.cjs
```

Windows 将 `./gradlew` 换为 `.\gradlew.bat`。完整环境、签名及原生测试见 [构建说明](docs/BUILD.md)。GitHub Actions 只构建独立包名的调试 APK，不包含发行签名或学校凭据。

| 目录 | 内容 |
| --- | --- |
| `app/src/main/java/edu/hitwh/fieldnote` | Android 登录、抓取任务、缓存、模型调用与提醒 |
| `app/src/main/assets` | 本地界面与学校页面解析脚本 |
| `tests` | 离线回归与脱敏页面样例 |
| `tools` | 测试、签名与界面预览生成脚本 |
| `docs` | 当前使用指南、更新说明及历史记录 |

下载 [preview.html](preview.html) 并在本地浏览器打开，可查看使用示例数据的界面。它不会登录学校，也不代表 Android 后台行为。
