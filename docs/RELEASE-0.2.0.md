# 汐序 0.2.0

## 此次修改

- “查询”和“用户”页顶部固定文案替换为随机名言、诗句或台词，附出处。每次新启动随机获取一次，两页共用本次文案；网络不可用时随机使用内置句库。
- 每次新启动自动进行一次教务同步；页面切换、旋转屏幕、从权限页面返回不重复启动同步。
- 状态提示可查看同步结果；同步异常保留本地缓存。

## 首次使用

1. 安装 APK，打开用户页保存账号，完成官方 VPN 登录。
2. 分别在课表、考试、成绩页面选择学期，读取此页，核对后保存。
3. 页面完整、学期标识可识别且地址可复用时，会提示“下次启动自动同步”。之后打开应用即可自动更新这些页面。
4. 如果提示“自动同步暂不可用”，该页面仍可手动导入；需针对实际学校页面进一步适配。没有编造学校接口或绕过登录。

启动同步按课表、考试、成绩顺序读取当前学期保存的页面，不自动翻页、提交登录或重试。页面之间间隔 1.8 秒，单页等待上限 20 秒。登录过期、分页、表格无法识别、缺失关键字段、学期变化或已有手动修正时保留旧数据。教务页面自身加载的资源由 WebView 正常请求。

## 安装说明

最低 Android 8.0。安装包为 debug 签名的测试版本；手机可能提示允许该来源安装应用。密码不会内置到包内，需在手机上自行填写。

如果已有同包名、不同签名的旧安装，不能直接覆盖；请先确认旧版数据已保留再处理。卸载会删除本地数据。

真实学校登录、学校页面解析和手机闹钟尚未完成真机联调。课表变化不会修改已安排的闹钟；请在提醒管理中调整。

名言来源：[一言公开接口文档](https://developer.hitokoto.cn/sentence/)。请求只包含类别与长度设置，不包含学号、密码、教务数据或备忘录。
