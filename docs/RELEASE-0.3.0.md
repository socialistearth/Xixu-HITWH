# 汐序 0.3.0

## 本次修复

- 按学校个人课表的实际格式解析教师、教室和方括号周次；同一格内的多段周次合并、去重，保留缺课周。
- 体育等页面未提供地点的课程保持为空，不猜测地点。
- “其它课程”中的网络课保留为自主安排课程，不随意放入某个时间格。
- “同步教务”改为一键顺序查询课表、考试、期末成绩，使用实际登录后菜单与页面确认的地址；不再要求先逐类读取再导入。
- 登录失效时，点击同步打开官方页面。完成登录后自动返回继续同步；学校要求的验证码仍需本人完成。
- 每次新启动仍自动同步一次；保留随机名言、备忘录及提醒功能。
- 同步修复旧版缺失字段，保留其他学期及已有手动修正。未发布的考试/成绩不清空缓存。

## 更新

安装 0.3.0 APK 覆盖 0.2.0，无需卸载。已确认包名相同、版本号递增、签名证书相同。仍建议保留原数据，不要先卸载。

打开应用后点击“同步教务”。若学校登录仍有效，会直接读取；过期时按官方页面完成认证。手动修改过的条目会保留并在同步提示中说明；如需完全改用学校数据，可使用“手动导入”核对后替换该学期。

账号、会话、密码没有打入 APK。首次使用或会话过期时仍需学校认证；“一键同步”不绕过验证码。

## 验证范围

本次通过安全认证成功进入真实教务系统，观察个人课表、考试详细查询、期末成绩查询及其学期控件。个人课表真实 DOM 的离线解析验证得到：17 条有固定时段的课程、17 个教师字段、16 个非空地点，以及 1 门未排固定时段的网络课。剩余 1 条体育课在原页面没有地点。

考试页和当前学期成绩查询当时显示空表，确认了页面表头、学期选择和查询流程，没有伪造示例考试/成绩代替实测。课程提醒仍需用户核对校历和作息；手机 WebView 的完整登录/同步流程、真机响铃和日历尚需在设备上验证。
