# 汐序 0.7.5：在当前页面同步与获取

## 操作变化

- “同步教务”和新闻“立即获取”在主界面的隐藏任务中执行，不再打开独立的连接页面。
- 任务进行时，原按钮显示旋转图标，按钮下方显示进度条与当前步骤。切换查询、新闻、用户选项卡后可以继续查看任务状态，不会重复启动。
- 学校要求验证码或进一步确认时，按钮变为“手动验证”。只有点击该按钮才显示学校网页；完成验证后自动继续，尚未完成而关闭网页时仍保留“手动验证”状态。
- 进度条表示任务阶段；需要等待学校响应或人工验证时使用不确定进度，不表示网络下载百分比。
- 教务和新闻共用学校登录会话，因此同时只运行一项学校任务。另一项进行中会说明原因，不打断原任务。
- 原有新闻缓存删除、待人工查看链接、课表与考试缓存删除、启动同步设置及新闻定时设置保留。

## 后台与数据

本次“后台”指任务在主界面后运行，切换应用内选项卡、暂时离开应用和旋转屏幕不主动暂停任务。任务进行时在查询主页按返回键会把应用放到后台。没有增加常驻前台服务；系统销毁活动或终止进程仍可能结束手动任务，不承诺被强制结束后继续运行。已保存缓存保留。

每天自动获取继续使用原有 Android 定时任务：需要人工验证时安静结束，不自动打开网页。手动获取和教务任务有等待上限，避免一直占用学校会话。修改账号、删除相关缓存或退出学校会话会停止对应任务；同步结果仍检查数据版本后写入。

## 安装

应用名保持“汐序”，包名 `edu.hitwh.fieldnote.news`，versionCode 15 / versionName 0.7.5。沿用固定签名，可覆盖安装 0.7.4 并保留数据。

本轮使用离线样例检查任务状态、按钮行为与登录流程，不额外访问学校或调用付费模型。未连接 Android 真机。
