# 汐序 0.4.1

自动登录时显示简洁的“正在连接教务”进度界面，学校网站页面与地址不再展示。登录成功后照常返回并同步数据。

APP / 短信验证码保留输入弹窗；图片、滑块验证使用学校页面弹窗，验证完成后隐藏网页并继续自动处理。异常时先在进度界面提示，仅在用户点击“手动完成验证”后显示学校页面。可以随时取消并返回。

隐藏的浏览器保持正常布局，维持原有账号表单识别及页面加载；禁止其获得焦点和无障碍朗读焦点，正常登录期间不会出现可点击的透明网页。“手动导入”保留可见网页。

用户已确认 0.4.0 一键登录可用。本轮依据现有流程调整显示方式，没有新增学校访问请求。构建和离线测试通过，0.4.1 的显示效果尚未真机验证。

与 0.4.0 同签名，版本 code 从 4 增至 5，可以覆盖安装，不需要卸载。
