# 汐序 0.4.0

- 移除防截屏限制，主界面及学校登录页面均可截图。
- 使用已加密保存的学号和密码，自动连接 VPN CAS 统一认证、学校账号登录和教务统一认证入口，成功后顺序同步课表、考试与成绩。
- 学校需要验证码时弹窗请求。可选择学校实际提供的 APP / 短信方式，用户点击获取和提交；不会自动发送短信。图片或滑块验证在学校原页面弹窗中完成。
- 启动自动同步增加开关和最短间隔：用户 → 提醒与数据。默认开启、60 分钟，可设 1–10080 分钟。间隔从最近一次实际同步尝试计算，失败也计入；手动同步可立即执行并重新计时。
- 取消登录不重复查询，登录成功仅继续一次；没有保存密码时提示先设置账号。原有课程、备忘录、作息与闹钟配置不因升级重置。

覆盖安装本次 APK，无需卸载旧版。安装包与 0.3.0 使用同一签名。

本轮根据此前实际验证的学校流程适配，没有新增学校登录请求。离线合成页面测试、原生时间策略测试及 Android 编译通过；本次自动认证仍需真机确认，不能把离线测试等同于手机实测。
