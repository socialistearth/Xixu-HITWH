# 汐序 0.7.6：新闻网读取与复制链接

## 本次修改

- 从校园 VPN 校主页发现的新闻，优先使用页面实际提供的代理链接；旧版未接入的本部新闻网 `news.hit.edu.cn` 文章可通过其官方 HTTPS 原文读取。
- 威海新闻网 `news.hitwh.edu.cn` 的 VPN 文章遇到连接、页面结构等技术故障时，对校主页明确关联的同一篇文章最多尝试一次官方 HTTPS 原文。不会将本部新闻替换为威海新闻，也不猜测代理加密地址。
- 两站独立去重：本部新闻网使用 `hit-news:a…`，威海保持 `hitwh-home:a…`，已有缓存和旧版待人工查看链接继续可用。
- 本部新闻网正文标题取实际文章标题，不再误取站点名称“新闻网”。
- 单篇文章失败后继续读取后面的文章；处理迟到的网页回调、暂停恢复和取消，避免替代读取阶段卡住。
- 每条已精选文章下增加“复制链接”。根据当前本地缓存核对文章后复制原文地址，不打开网页、不重新抓取；删除后的旧按钮不能复制到另一篇文章。

继续保留近七天窗口、单次最多20篇新文章、串行访问及页面间间隔。替代请求每篇至多一次；登录或明确访问受限页面不会反复重试。后台进度、手动验证、新闻缓存删除和未识别链接展示保持现有操作方式。

## 安装

应用名称仍为“汐序”；包名 `edu.hitwh.fieldnote.news`；versionCode 16 / versionName 0.7.6。使用与 0.7.5 相同的签名，可覆盖安装，无需卸载、清空缓存或重新填写配置。

## 核实与验证范围

本次少量读取学校公开页面：校主页、威海新闻网一篇文章、本部新闻网一篇文章。主页“工大要闻”本来就包含本部新闻网链接，“校区新闻”则链接威海新闻网，不能互换域名。

- 两篇样例公开 HTTPS 页面均返回200；原始 HTML 中均有 `.wp_articlecontent`。
- 用生产解析脚本和实际首页 HTML 做离线 DOM 验证，按北京时间2026年9月28日、空去重集合识别出14篇近期候选，包括4篇本部新闻网和1篇威海新闻网文章。候选数量不是模型精选数量，也不代表遍历了学校所有栏目。
- 用生产脚本解析两站实际文章 HTML，分别取得1481和1854字正文，标题、站点及文章编号正确。真实文章 HTML 仅用于临时验证，未打入源码或 APK。
- JavaScript 回归150项通过，其中新闻解析31项。
- 新闻数据与复制链接95项、缓存151项、模型选择契约135项离线检查通过。
- 新闻客户端既有状态流程43项检查通过。
- 新增抓取器原生生命周期19项检查通过，覆盖同篇替代一次、计数、迟到回调、暂停恢复、取消和地址限制。
- 真实本地界面的 JSDOM 点击测试通过：复制参数、示例模式、已删除记录及文本转义均正常；测试无外部网络请求。此测试不验证手机布局。

没有调用付费精选模型，没有通过本次远程浏览器完成 VPN 登录，也没有连接 Android 真机。因此以上结果分别证明公开页面可读、解析和任务逻辑通过测试，不能当作手机 VPN 端到端实测记录。威海新闻网原 VPN 路径失败的具体服务端原因仍未复现，本次以严格限制的同篇官方 HTTPS 替代处理这类失败。
