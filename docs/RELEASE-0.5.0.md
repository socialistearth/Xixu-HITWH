# 汐序 0.5.0 · 校园新闻

新增“查询 / 新闻 / 用户”三个并列选项卡。配套校园日报 Docker v3 保留原来的学校来源、2026级动态年级/学期筛选、AI 简介和去重，将原微信发送改为事务化新闻收件箱。

App 增加 HTTPS + 访问密钥连接、增量接收、未读标记、摘要与原文、离线缓存。接收新闻不调用学校或模型。默认 30 分钟后台检查，可调整或关闭；新日报发通知，点击直接进入新闻。首次历史导入静默。

保留 0.4.1 的隐藏统一认证、验证码弹窗、教务同步间隔、截图、备忘录、随机名言、课程与考试提醒。

由于原签名私钥丢失，本次交付独立包名 edu.hitwh.fieldnote.news，应用名“汐序·新闻版”。可以与旧版并存，不能覆盖旧版本，旧资料不会自动迁入。新版固定签名单独备份，源码不含私钥。

使用步骤见 NEWS-SETUP.md；测试与限制见 VALIDATION.md。尚未代为部署到真实 Docker 主机，未在手机上验证后台接收。
