# 汐序 0.7.4：新闻缓存删除与待人工查看链接

## 新闻缓存删除

- 在精选详情中，每篇新闻下方有“删除这条新闻缓存”。
- 详情底部有“删除这份精选”，删除整份记录及其中的未识别链接。
- 新闻列表底部有“清空新闻缓存”，清理全部精选、待展示内容及独立保存的待人工查看记录。
- 操作前有确认。若新闻获取正在进行，会停止该任务并阻止旧结果覆盖删除操作。
- 删除只影响本机新闻内容，保留账号、模型配置、定时设置、课表和备忘录。保留已处理标记，避免删除后马上重复精选；未识别链接不标记为已处理。
- 删除某份精选的最后一篇新闻后，保留该份记录及待人工查看链接，并显示新闻缓存已删除。原获取统计保留，另显示已删除数量。

## 未识别链接

新获取的精选详情底部增加“待人工查看的链接”：显示标题、日期、原始学校网址和未处理原因，支持打开和复制。不会为了列出这些链接增加学校请求或调用模型。

链接仍没有通过自动正文读取，不算已完成的精选。普通原站链接使用系统浏览器，受限正文可能需要通过学校 VPN 查看；已有合规 VPN 地址使用应用内原文页。

即使整轮没有任何可自动读取的文章，识别出的安全学校链接仍会单独保留在新闻主列表，获取状态继续显示失败，不制造“成功、零条精选”。

仅保存页面实际出现的近期学校文章链接，最多 40 条；按文章编号去重，排除已处理或已经成功解析的条目。网址清除临时查询参数及片段，不保存登录凭据。链接打开与复制均从当前缓存解析，并检查编号，避免打开已被替换的旧列表项。

旧版本仅保存了未识别数量，没有保存具体网址，无法补出截图那一份记录的四个链接。覆盖更新后，下次获取会保存并显示实际未识别的链接；无需清空旧缓存。

## 安装

名称仍为“汐序”，包名 `edu.hitwh.fieldnote.news`，versionCode 14 / versionName 0.7.4。使用原固定签名，直接覆盖 0.7.3 即可保留数据。

本轮没有重新登录学校或调用付费模型；使用离线样例验证新增功能。0.7.3 已由用户确认可用的登录及资源导航逻辑保持不变。未连接 Android 真机。
