# 汐序 0.7.0 更新说明

新闻精选从 Docker 迁移到手机：App 通过校园 VPN 打开“校主页”，只从实际页面发现并跟随文章链接，再调用本机配置的模型进行精选。学校首页中的不同 VPN 代理路径均按实际发现的链接处理，不从旧版公开站点列表开始抓取。使用新闻功能不再需要自建服务器。

## 本次变化

- 新闻页保留手动获取，并支持每天按指定北京时间安排一次自动获取，默认时间为 19:00。
- 自动获取失败时安静结束，不打开学校页面、不弹验证码或失败通知；需要本人验证时，由用户主动点击“立即获取”处理。
- 手动登录沿用教务的隐藏页面流程，只在需要验证码或本人操作时展示相应界面。
- 自动从 VPN 资源门户选择“校主页”或“新教务系统”，减少手动点选资源卡片。
- 手机配置模型 HTTPS API 地址、模型名称、API Key 与关注方向。凭据本机加密保存；文章与关注方向发送给所选模型，学校账号、密码和 VPN Cookie 不发送给模型。
- 保留原有离线新闻与已读状态，停止使用旧新闻服务器连接设置；旧已接收文章参与去重，避免因为迁移而重复精选。
- “查看学校原文”使用 App 内学校浏览器，继续使用校园 VPN 会话。
- 应用名称仍为“汐序”。包名 `edu.hitwh.fieldnote.news`，版本号 `0.7.0`，versionCode `10`，沿用固定签名，支持覆盖更新 0.5.x / 0.6.0。

原有查询、课程与考试提醒、备忘录、单条缓存删除和批量清理保持可用。课程启动自动同步的开关与间隔独立于新闻每日任务。

## 使用与迁移

具体操作见 `docs/NEWS-SETUP.md`。手机首次需要重新填写模型 API 配置；旧服务器里的模型设置不会自动传入手机。

先保留原 App 并覆盖安装新 APK，确认一次手动获取成功，再参考 `docs/UNINSTALL-DOCKER.md` 停止旧新闻服务。App 缓存不等于完整服务器备份；默认卸载方案保留服务数据卷。

## 运行限制

Android 后台任务受系统省电、网络、厂商后台限制影响，指定时间为计划时间，不保证整点到达。强行停止 App 后需要重新打开才能恢复任务。后台需要学校验证时，本轮安静结束，用户可稍后主动获取。

学校页面结构与认证规则可能变化，自动入口识别有范围和次数限制。仅凭一份页面样本无法保证所有学校页面都已兼容。

## 验证状态

85 项 JavaScript 测试、120 项本地模型与时间策略检查、41 项新闻数据检查及 101 项查询缓存检查通过。最终 Release APK 已完成清理编译并通过签名校验，沿用原安装包签名。手机尺寸的新闻设置与立即获取流程、首页与正文 DOM 提取均通过离线浏览器验证，模型使用替代响应，没有调用真实模型 API。

2026 年 9 月 21 日已在真实浏览器中经校园 VPN 打开“校主页”，并成功读取先前失败的《关于清理废置（弃）自行车的通知》正文，确认其 `.htm` 地址跳转到同一篇文章的 `page.psp`。资源门户实际卡片 DOM 已加入离线回归样本，覆盖卡片标题本身没有跳转链接的情况。

本轮已核对“新教务系统”资源入口能进入教务统一身份认证页面；尚不能据此宣称完整教务登录和查询已完成。未调用付费模型 API，尚未在真实 Android 手机验证锁屏后的定时任务与厂商省电策略，也未在你的服务器执行卸载。
