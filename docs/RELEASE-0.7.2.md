# 汐序 0.7.2：零结果核查与抓取诊断

## 已确认的问题与变更

- 旧版在校主页未识别到文章链接时，也可能保存“0 条精选”。新版最多再检查三次已加载的页面内容，不额外刷新学校页面；仍未识别则报抓取未完成，不调用模型、不生成成功日报。
- 每份新记录保存近期文章、已处理、排队、正文读取、正文失败、本次模型判断、入选和此前待展示精选的数量。
- 区分没有近期文章、近期文章已处理、模型未选中和部分处理未完成。旧记录没有统计，明确说明无法反推是否漏抓。
- 登录进度界面增加“复制登录诊断”。记录页面类别、资源卡片数量、脚本执行结果、App/Android/WebView 版本和最近状态；不收集账号、密码、验证码、Cookie、完整地址或查询参数。
