# 汐序 0.5.1 更新

增加“课表 / 考试缓存删除”：在对应查询页点“清除缓存”，或进入“用户 → 提醒与数据 → 清理课表 / 考试缓存”。选择类型及当前学期/全部学期，查看条数，二次确认后删除。

删除包括所选范围的查询记录（含手动修正）、对应导入信息；清课表时也删除对应课程颜色。所选范围该类型待确认的导入结果会清除。账号、密码、成绩、备忘录、新闻、校历与作息设置保留。已设置的闹钟和系统日历日程继续有效，需要时另外取消。

清理只操作本地，停止正在进行的教务同步，并阻止旧结果随后写回；不会因为清理立即访问学校。之后手动同步或符合自动同步条件时，可以重新获取。若不希望下次启动自动获取，可关闭原有“启动时自动同步教务”开关。

包名 edu.hitwh.fieldnote.news；versionCode 7 / versionName 0.5.1。沿用 0.5.0 的固定签名，可直接覆盖安装“汐序·新闻版 0.5.0”并保留资料。不适用于覆盖旧 0.4.x 包名。

配套 Docker v3.1 是面向全新服务器的完整项目，新增 configure.py、start.sh 与 INSTALL.md，内含全部源码和构建配置，不需要旧部署文件。首次构建仍需要联网获取镜像和依赖。
