# 汐序 0.7.1 修复说明

针对 0.7.0 的两张实机反馈截图，修复校主页验证停留、VPN 资源入口未自动打开及教务认证恢复流程。应用名称、包名、签名和本地数据格式不变，直接覆盖安装，不要先卸载或清除应用数据。

## 校主页与资源入口

旧版识别校主页时依赖资源点击回调保存的临时地址。真实主页没有备用识别所需的 SiteDomain 元数据，手动进入或丢失回调时会被判为未知页面，继续停在验证弹窗。

本版根据此前实测的校主页 VPN 路径、学校标题及主页导航/文章结构识别完成状态；同时支持 main.psp、index.psp。识别完成后自动关闭验证弹窗并继续新闻获取，不要求再点“完成验证”。仍会拒绝其他站点、登录页、空白页和单篇文章冒充主页。

VPN 门户中的“校主页”和“新教务系统”卡片使用占位链接和网页点击事件。现在读取名称与原站地址相符的资源卡片后，由 Android 在现有 WebView 打开已核验入口，不再依赖网页新窗口或跳转时可能丢失的 JavaScript 回调。资源卡片在屏幕下方也能识别。

## 教务同步

开始同步时，先经 VPN 门户确认教务登录，再顺序查询课表、考试和成绩。登录成功后只继续一次；取消登录不查询，也不会循环重新认证。

旧版把所有主页面 HTTP 错误都归为普通网络故障，登录过期时可能无法触发重新认证。本版区分 401/403 及明确要求登录的错误页面，保留真实 404、429、5xx 等错误不重试的限制。错误提示显示查询类型与 HTTP 状态码，方便后续定位。

截图二没有提供 HTTP 状态码，因此无法断言当时具体是哪一种服务端错误。本次修复覆盖认证前直接访问查询页及错误分类缺口，不代表能修复学校服务器自身的故障。

## 安装与设置

- 直接覆盖安装 0.7.0，保留课程、考试、成绩、备忘录、账号、新闻及模型配置。
- 无需重新部署 Docker，也不需要重新填写模型设置。
- 0.7.0 的新闻每日定时与立即获取继续可用，自动新闻任务失败仍静默结束。
- 版本：0.7.1，versionCode 11；包名：edu.hitwh.fieldnote.news；最低 Android 8.0。

## 验证范围

先用本地样本复现“无临时地址、无元数据主页不被识别”和“资源检测没有返回可直接打开的地址”两项失败，再修复并验证。

94 项 JavaScript 回归检查通过，涵盖新闻、教务、登录及缓存流程；39 项教务认证与 HTTP 分类 Java 检查通过。Chromium 手机尺寸回归验证了屏幕下方卡片、无需网页弹窗打开目标、主页识别与 PSP 路径。教务继续流程验证认证前不发出查询、认证后仅继续一轮。

本轮没有访问学校服务器，也没有调用模型 API；测试使用之前核验的页面结构和合成数据。尚未在真实 Android 手机上运行本次修复，桌面浏览器检查不能替代实机 WebView 验证。
